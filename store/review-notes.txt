turtl is an on-call assistant for people who run a live app without an operations team. It watches the owner's app, opens a case when a check fails or a customer reports a problem, explains the likely cause, and proposes fixes. Nothing changes in the owner's app until the owner approves it.

SIGNING IN
Use the review account in the sign-in fields of this submission. It is an email and password account. New accounts can also be created with Sign in with Apple or GitHub.

WHAT THE REVIEW ACCOUNT CONTAINS
A new account starts empty. It can connect a GitHub repository and a live app, or try a practice app that turtl runs for it. The review account has one project, "Practice booking app" (marked Practice), connected to a small booking app we run only for testing and review, with a case already open.
1. If turtl first asks about AI services, tap Allow or Not now. The case works either way: without permission turtl explains the problem with its own rules.
2. On Projects, tap Practice booking app, then Fix, then the issue "Booking is failing" (or swipe up to begin review).
3. Read the Overview, Logs, and Code tabs. The practice app has no repository, so Code says there is no code to show.
4. Tap "Look at potential fixes", then Approve on "Turn off recommendations", then Approve on the sheet. turtl turns recommendations off in the practice app, then runs its booking check again to confirm bookings work. The next screen shows each step.
5. To do it again: on the project page, tap Break it, choose what goes wrong, and tap Break it. Within a minute or two a new issue opens under Fix. Approve the fix turtl offers, as in step 4. This works up to 10 times a day.
6. On the project page, tap the gear for Settings: who approves fixes, AI services, Privacy policy, Terms, Support, and Account.
It only ever touches the review account's own practice app.

THIRD-PARTY AI (5.1.2)
turtl sends parts of the owner's source code, case details, messages, and voice recordings to third-party AI services: OpenAI, Supermemory, Capy, and Keiki. Before anything is sent, the app shows a screen that names each service and what it receives, and asks for permission. Permission can be withdrawn in Settings. The privacy policy lists the same services.

MICROPHONE (2.5.14)
Used only after the user taps Talk on a case, and the app shows that it is listening. A recording is at most 30 seconds. It is sent to OpenAI to be turned into text and is not stored. Typing does the same job if the user declines.

ACCOUNT DELETION (5.1.1(v))
Project page, gear, Account, Delete account. This deletes the account and its data, including the copies held by our search provider.

PURCHASES (3.1)
turtl is free. It has no in-app purchases, subscriptions, or advertising, and no links to buy anything.

OTHER
- Code changes are written on our servers and arrive as a pull request on GitHub. The app does not download or run code.
- People who use turtl cannot message each other, and nothing they write is shown to other users.
- The app needs a network connection. Our backend is running for the review.
